# Regret Bounds for Satisficing in Multi-Armed Bandit Problems

Code for the experiments of the paper

## Usage
The file `bandit.py` contains different class for bandits as well as the code to run the algorithms considered in this study. Please refer to the comments at the begining of the file for usage.

The files `bernoulli_experiment.py` and `gaussian_experiment.py` reproduces the figures used in the paper. Each file runs all the experiments before showing the plots. It may take a few minutes.
